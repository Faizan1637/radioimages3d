# RadioImages — Dental Imaging Center Website

Modern Next.js website for **RadioImages 3D Dental Imaging Center** (DHA Lahore).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Key features

- WhatsApp-first booking (no form / no patient data collection on-site)
- Service pages for CBCT, OPG, CEPH, endodontic imaging, surgical guides and more
- Planmeca ProMax 3D Classic technology page with interactive volume compare
- LocalBusiness + FAQ JSON-LD, sitemap and robots.txt
- Sticky mobile WhatsApp CTA, click-to-call and Google Maps directions

## Content notes

- Address, phones and hours are configured in `src/lib/site.ts`
- Service and FAQ copy lives in `src/lib/content.ts`
- Brand and brochure images are in `public/images/`
